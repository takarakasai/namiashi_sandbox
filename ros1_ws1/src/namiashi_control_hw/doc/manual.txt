単一モーターコマンド
同じバス上には最大32台（バス負荷状況による）のドライバを接続できます。バスの衝突を防ぐため、各ドライバには異なるID（1～32）を設定する必要があります。
ホストはバスに単一モーターコマンドフレームを送信し、対応するIDのモーターがコマンドを受信すると実行し、一定時間後（0.25ms以内）に同じIDの返信フレームをホストに送信します。コマンドフレームと返信フレームのフォーマットは以下の通りです：フレームコマンド＋フレームデータ（オプション）、詳細は下表参照。

1. モーター状態1とエラーフラグの読み取りコマンド
このコマンドは現在のモーター温度、電圧、エラー状態フラグを読み取ります。

フレームコマンド（5バイト、チェックサム含む）
CMD[0] フレームヘッダ 0x3E
CMD[1] コマンド 0x9A
CMD[2] ID 0x01～0x20
CMD[3] データ長 0x00
CMD_SUM フレームコマンドのチェックサムバイト（CMD[0]～CMD[3]のチェックサム）

ドライバ応答
モーターがコマンドを受信すると、ホストに応答し、応答データに以下のパラメータが含まれます：
1. モーター温度 temperature（int8_t型、単位1℃/LSB）
2. バス電圧 voltage（int16_t型、単位0.01V/LSB）
3. バス電流 current（int16_t型、単位0.01A/LSB）
4. モーター状態 motorState（uint8_t型、各ビットが異なる状態を示す）
5. エラーフラグ errorState（uint8_t型、各ビットが異なるエラー状態を示す）

フレームコマンド（5バイト、チェックサム含む）
CMD[0] フレームヘッダ 0x3E
CMD[1] コマンド 0x9A
CMD[2] ID 0x01～0x20
CMD[3] データ長 0x07
CMD_SUM フレームコマンドのチェックサムバイト（CMD[0]～CMD[3]のチェックサム）

フレームデータ（8バイト、チェックサム含む）
DATA[0] モーター温度
DATA[0] = *(uint8_t *)(&temperature)
DATA[1] バス電圧下位バイト
DATA[1] = *(uint8_t *)(&voltage)
DATA[2] バス電圧上位バイト
DATA[2] = *((uint8_t *)(&voltage)+1)
DATA[3] バス電流下位バイト
DATA[3] = *(uint8_t *)(&current)
DATA[4] バス電流上位バイト
DATA[4] = *((uint8_t *)(&current)+1)
DATA[5] モーター状態バイト
DATA[5] = motorState
DATA[6] エラー状態バイト
DATA[6] = errorState
DATA_SUM データチェックサムバイト（DATA[0]～DATA[6]のチェックサム）

備考：
1. motorState = 0x00 モーターはON状態、motorState = 0x10 モーターはOFF状態。
2. errorState各ビットの状態表は以下の通り

errorStateビット
状態説明
0
低電圧状態：正常/低圧保護
1
高電圧状態：正常/高圧保護
2
ドライバ温度状態：正常/過温
3
モーター温度状態：正常/過温
4
モーター電流状態：正常/過電流
5
モーター短絡状態：正常/短絡
6
ロック状態：正常/ロック
7
入力信号状態：正常/入力信号喪失タイムアウト

2. モーターエラーフラグのクリアコマンド
このコマンドは現在のモーターエラー状態をクリアします。モーターが受信後、返信します。

フレームコマンド（5バイト、チェックサム含む）
CMD[0] フレームヘッダ 0x3E
CMD[1] コマンド 0x9B
CMD[2] ID 0x01～0x20
CMD[3] データ長 0x00
CMD_SUM フレームコマンドのチェックサムバイト（CMD[0]～CMD[3]のチェックサム）

ドライバ応答
モーターがコマンドを受信すると、ホストに返信します。返信データは「モーター状態1とエラーフラグの読み取りコマンド」と同じ（コマンドバイトCMD[1]のみ異なり、ここでは0x9B）。

備考：
1. モーター状態が正常に戻っていない場合、エラーフラグはクリアできません。

12. 多回転位置クローズドループ制御コマンド1
ホストがこのコマンドを送信することで、モーターの位置（多回転角度）を制御します。制御値 angleControl は int64_t 型で、実際の位置は 0.01°/LSB、つまり 36000 で 360° となります。モーターの回転方向は目標位置と現在位置の差で決まります。

フレームコマンド（5バイト、チェックサム含む）
CMD[0] フレームヘッダ 0x3E
CMD[1] コマンド 0xA3
CMD[2] ID 0x01～0x20
CMD[3] データ長 0x08
CMD_SUM フレームコマンドのチェックサムバイト（CMD[0]～CMD[3]のチェックサム）

フレームデータ（9バイト、チェックサム含む）
DATA[0] 位置制御下位バイト1
DATA[0] = *(uint8_t *)(&angleControl)
DATA[1] 位置制御バイト2
DATA[1] = *((uint8_t *)(&angleControl)+1)
DATA[2] 位置制御バイト3
DATA[2] = *((uint8_t *)(&angleControl)+2)
DATA[3] 位置制御バイト4
DATA[3] = *((uint8_t *)(&angleControl)+3)
DATA[4] 位置制御バイト5
DATA[4] = *((uint8_t *)(&angleControl)+4)
DATA[5] 位置制御バイト6
DATA[5] = *((uint8_t *)(&angleControl)+5)
DATA[6] 位置制御バイト7
DATA[6] = *((uint8_t *)(&angleControl)+6)
DATA[7] 位置制御上位バイト8
DATA[7] = *((uint8_t *)(&angleControl)+7)
DATA_SUM データチェックサムバイト（DATA[0]～DATA[7]のチェックサム）

備考：
1. このコマンドの angleControl は上位機器の Max Angle 値で制限されます。
2. このコマンドの最大速度は上位機器の Max Speed 値で制限されます。
3. この制御モードでは、モーターの最大加速度は上位機器の Max Acceleration 値で制限されます。
4. この制御モードでは、MF、MH、MG モーターの最大トルク電流は上位機器の Max Torque Current 値で制限され、MS モーターの最大出力は Max Power 値で制限されます。

ドライバ応答
モーターがコマンドを受信するとホストに返信します。返信データは「モーター状態2の読み取りコマンド」と同じ（コマンドバイト CMD[1] のみ異なり、ここでは 0xA3）。

13. 多回転位置クローズドループ制御コマンド2
ホストがこのコマンドを送信することで、モーターの位置（多回転角度）を制御します。
1. 制御値 angleControl は int64_t 型で、実際の位置は 0.01°/LSB、つまり 36000 で 360° となります。モーターの回転方向は目標位置と現在位置の差で決まります。
2. 制御値 maxSpeed はモーターの最大速度を制限し、uint32_t 型で、実際の速度は 0.01dps/LSB、つまり 36000 で 360dps となります。

フレームコマンド（5バイト、チェックサム含む）
CMD[0] フレームヘッダ 0x3E
CMD[1] コマンド 0xA4
CMD[2] ID 0x01～0x20
CMD[3] データ長 0x0C
CMD_SUM フレームコマンドのチェックサムバイト（CMD[0]～CMD[3]のチェックサム）

フレームデータ（13バイト、チェックサム含む）
DATA[0] 位置制御下位バイト1
DATA[0] = *(uint8_t *)(&angleControl)
DATA[1] 位置制御バイト2
DATA[1] = *((uint8_t *)(&angleControl)+1)
DATA[2] 位置制御バイト3
DATA[2] = *((uint8_t *)(&angleControl)+2)
DATA[3] 位置制御バイト4
DATA[3] = *((uint8_t *)(&angleControl)+3)
DATA[4] 位置制御バイト5
DATA[4] = *((uint8_t *)(&angleControl)+4)
DATA[5] 位置制御バイト6
DATA[5] = *((uint8_t *)(&angleControl)+5)
DATA[6] 位置制御バイト7
DATA[6] = *((uint8_t *)(&angleControl)+6)
DATA[7] 位置制御上位バイト8
DATA[7] = *((uint8_t *)(&angleControl)+7)
DATA[8] 速度制限下位バイト1
DATA[8] = *(uint8_t *)(&maxSpeed)
DATA[9] 速度制限バイト2
DATA[9] = *((uint8_t *)(&maxSpeed)+1)
DATA[10] 速度制限バイト3
DATA[10] = *((uint8_t *)(&maxSpeed)+2)
DATA[11] 速度制限上位バイト4
DATA[11] = *((uint8_t *)(&maxSpeed)+3)
DATA_SUM データチェックサムバイト（DATA[0]～DATA[11]のチェックサム）

備考：
1. このコマンドの angleControl は上位機器の Max Angle 値で制限されます。
2. この制御モードでは、モーターの最大加速度は上位機器の Max Acceleration 値で制限されます。
3. この制御モードでは、MF、MH、MG モーターの最大トルク電流は上位機器の Max Torque Current 値で制限され、MS モーターの最大出力は Max Power 値で制限されます。

ドライバ応答
モーターがコマンドを受信するとホストに返信します。返信データは「モーター状態2の読み取りコマンド」と同じ（コマンドバイト CMD[1] のみ異なり、ここでは 0xA4）。

21. 現在位置をモーターゼロ点として設定するコマンド（ROM書き込み）
モーターの現在位置のエンコーダ生値を、モーターの電源投入後の初期ゼロ点として設定します。
注意：
1. このコマンドはゼロ点をドライバのFLASHに書き込みます。頻繁な書き込みはチップの寿命に影響するため、頻繁な使用は推奨しません。

フレームコマンド（5バイト、チェックサム含む）
CMD[0] フレームヘッダ 0x3E
CMD[1] コマンド 0x19
CMD[2] ID 0x01~0x20
CMD[3] データ長 0x00
CMD_SUM フレームコマンドのチェックサムバイト（CMD[0]~CMD[3]のチェックサム）

ドライバ応答
モーターがコマンドを受信すると、ホストに応答し、応答データに以下のパラメータが含まれます。
1. 現在位置のエンコーダ生値 encoderZero

フレームコマンド（5バイト、チェックサム含む）
CMD[0] フレームヘッダ 0x3E
CMD[1] コマンド 0x19
CMD[2] ID 0x01~0x20
CMD[3] データ長 0x02
CMD_SUM フレームコマンドのチェックサムバイト（CMD[0]~CMD[3]のチェックサム）

フレームデータ（3バイト、チェックサム含む）
DATA[0] ゼロ点エンコーダ生値下位バイト
DATA[0] = *(uint8_t *)(&encoderZero)
DATA[1] ゼロ点エンコーダ生値上位バイト
DATA[1] = *((uint8_t *)(&encoderZero)+1)
DATA_SUM データチェックサムバイト（DATA[0]~DATA[1]のチェックサム）
